Política de Privacidade

Última atualização: 28/09/2026

1. Sobre a política

Esta política explica quais dados são usados pelo sistema Mistral e para que eles são utilizados.

2. Dados utilizados

O sistema utiliza dados dos funcionários, como nome, matrícula, cargo, senha e perfil. Também são registrados alguns dados sobre as ações realizadas no sistema para fins de auditoria.

3. Para que os dados são usados

Os dados são utilizados para identificar os funcionários, permitir o login, controlar o acesso ao sistema e registrar operações realizadas pelos usuários.

4. Onde os dados são armazenados

Os dados utilizados pelo sistema são armazenados no banco de dados PostgreSQL. As senhas são armazenadas de forma protegida usando BCrypt.

5. Acesso aos dados

O acesso aos dados depende do perfil do funcionário. O perfil ADMIN possui acesso às operações administrativas, enquanto o perfil USUARIO possui acesso às consultas permitidas pelo sistema.

6. Auditoria

Algumas ações realizadas no sistema são registradas para manter um histórico das operações. Esses registros podem conter a matrícula do funcionário, a operação realizada, uma descrição e a data e hora.

7. API externa

O Mistral utiliza a BrasilAPI para consultar informações sobre feriados. Para essa consulta, não são enviados dados pessoais dos funcionários.

8. Retenção dos dados

Os dados serão mantidos enquanto forem necessários para o funcionamento do sistema. Quando não forem mais necessários, deverão ser excluídos ou anonimizados, conforme o caso.

9. Direitos dos funcionários

Os funcionários poderão solicitar informações sobre seus dados pessoais e, quando necessário, pedir a correção ou exclusão dessas informações.

10. Segurança

O sistema possui mecanismos de autenticação, controle de acesso, proteção das senhas e registro de operações para ajudar na segurança das informações.

11. Incidentes de segurança

Caso ocorra um problema de segurança, o incidente deverá ser identificado, isolado e analisado. Também deverá ser verificado se algum dado foi afetado e quais medidas devem ser tomadas.

12. Alterações nesta política

Esta política poderá ser alterada quando houver mudanças no sistema ou na forma como os dados são utilizados.

13. Projeto acadêmico

O Mistral é um projeto acadêmico desenvolvido como Projeto de Final de Curso. Em uma aplicação real, as regras relacionadas ao uso e à proteção dos dados deverão ser avaliadas pelos responsáveis pelo sistema.
