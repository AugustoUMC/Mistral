Termos de Uso

Última atualização: 28/09/2026

1. Sobre o sistema

O Mistral é um sistema desenvolvido para auxiliar no controle e acompanhamento da produção de uma fábrica, permitindo o gerenciamento de funcionários, grupos, produtos e metas.

2. Uso do sistema

O sistema deve ser utilizado somente para as atividades relacionadas ao controle da produção e às funções disponíveis para cada usuário.

3. Conta e acesso

Cada funcionário que possuir acesso ao sistema deverá utilizar sua própria matrícula e senha. Os dados de acesso não devem ser compartilhados com outras pessoas.

4. Perfis e permissões

O sistema possui diferentes níveis de acesso. O perfil ADMIN possui permissões para operações administrativas, enquanto o perfil USUARIO possui acesso às consultas permitidas pelo sistema.

5. Responsabilidade do usuário

O usuário deve utilizar o sistema de forma correta e manter seus dados de acesso protegidos. Também deve evitar realizar operações que não estejam relacionadas às suas funções.

6. Dados e informações

As informações cadastradas no sistema devem estar relacionadas às atividades da fábrica. O usuário deve evitar inserir informações que não sejam necessárias para o funcionamento do sistema.

7. Segurança

O sistema possui mecanismos de autenticação, controle de acesso, proteção das senhas e registro de operações para aumentar a segurança das informações.

8. Disponibilidade do sistema

O sistema poderá ficar indisponível durante manutenções, atualizações ou problemas técnicos. Quando necessário, essas situações deverão ser tratadas pelos responsáveis pelo sistema.

9. Uso indevido

Não é permitido utilizar o sistema para acessar informações sem autorização, alterar dados de forma indevida ou tentar contornar os controles de segurança existentes.

10. Encerramento do acesso

O acesso de um funcionário poderá ser encerrado quando ele deixar de possuir autorização para utilizar o sistema.

11. Alterações dos termos

Estes termos poderão ser alterados quando houver mudanças no sistema ou na forma como ele é utilizado.

12. Projeto acadêmico

O Mistral é um projeto acadêmico desenvolvido como Projeto de Final de Curso. Em uma aplicação real, regras adicionais poderão ser definidas pelos responsáveis pelo sistema.
